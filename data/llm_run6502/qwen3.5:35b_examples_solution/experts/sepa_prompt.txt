### Process description:
Nach Eingang der Daten für ein SEPA-Mandat wird zunächst geprüft, ob eine IBAN vorliegt, um das Bankkonto des Zahlers eindeutig zu identifizieren. Anhand der ersten beiden Stellen der IBAN wird festgestellt, in welchem Land das Konto registriert ist. Im nächsten Schritt erfolgt die Suche nach der zugehörigen Person im System. Dabei wird kontrolliert, ob alle erforderlichen Informationen vorhanden sind. Dazu zählen: •	die Person selbst, •	eine gültige Unterschrift, •	eine vollständige IBAN, •	das Eingangsdatum des Mandats, •	der Ort der Unterschrift, •	sowie die Bestätigung, dass kein abweichender Kontoinhaber existiert. Sollten nicht alle notwendigen Angaben vorhanden sein, wird je nach Situation unterschieden: Liegt eine Unterschrift vor, erfolgt eine manuelle Prüfung der fehlenden Daten. Fehlt die Unterschrift, wird automatisch ein Schreiben erstellt, das die fehlende Unterschrift anfordert. In diesem Fall wird eine Rückmeldung innerhalb von 28 Tagen abgewartet; bleibt diese aus, kann der Prozess nicht weitergeführt werden. Sind alle erforderlichen Informationen vollständig, wird geprüft, ob ein "Gültig von"-Datum vorhanden ist, welches den Beginn der Gültigkeit des SEPA-Mandats kennzeichnet. Zudem wird nochmals kontrolliert, ob der Unterschriftsort und das Datum korrekt erfasst wurden und ob eine gültige Bankverbindung im System hinterlegt ist. Fehlt eine Bankverbindung oder liegt ein Fehler vor, wird diese entweder neu erstellt oder von einem Sachbearbeiter geprüft. Nach Anlage oder Bestätigung der Bankverbindung wird überprüft, ob bereits ein aktives SEPA-Mandat für die betreffende Person existiert. Falls kein aktives Mandat vorhanden ist, wird ein neues Mandat angelegt, vorausgesetzt, es liegt ein gültiges Unterschriftsdatum vor. Existiert bereits ein aktives Mandat, wird kontrolliert, ob das neue Mandat gültig und relevant ist. Dazu muss geprüft werden, dass: •	das neue Mandat nicht älter ist als das bestehende Mandat, •	das „Gültig von“-Datum korrekt ist, •	sowie das Unterschriftsdatum ordnungsgemäß angegeben wurde. Erfüllt das neue Mandat diese Bedingungen, wird das bestehende Mandat beendet und ein neues SEPA-Mandat im System angelegt. Abschließend erfolgt eine Prüfung auf offene Forderungen. Dabei wird kontrolliert, ob unbezahlte Rechnungen bestehen. Diese werden entsprechend zugeordnet und der betroffenen Person kommuniziert, einschließlich der jeweiligen Beträge. Überschreiten die offenen Forderungen eine Höhe von 5.000 €, muss eine zusätzliche manuelle Überprüfung erfolgen, bevor das SEPA-Mandat endgültig abgeschlossen werden kann.
