# BEF4LLM

This repository contains the source code accompanying the paper:

*Assessing the Business Process Modeling Competences of Large Language Models*

It provides the tools and code to evaluate BPMN models across three quality dimensions: syntactic, semantic, and pragmatic. The evaluation is based on a set of well-defined metrics. Based on that, we developed a pipeline to analyze the ability of large language models (LLMs) to generate BPMN diagrams from textual descriptions. This analysis is conducted using a dataset of 105 text-model pairs, evaluated using the aforementioned metrics.

For comparison, we also assess the performance of human experts in process modeling using a smaller dataset of 9 text-model pairs.
